## Long description

PetToStitch is a free browser-based tool for turning pet photos into practical cross-stitch patterns. Users can crop a portrait, remove distracting backgrounds, select the stitch width and thread color count, and edit individual cells before exporting a color chart or printable symbol pattern. The tool uses DMC-style thread references and calculates the finished size and stitch count automatically. Photos are processed locally in the browser and are not uploaded, and no account is required.

## Founder comment

I built PetToStitch to make custom pet portraits easier to start. Most photo converters produce a result and stop there, so I added cropping, background removal, an editable stitch grid, DMC-style thread references, and printable symbol charts. Everything runs locally in the browser, which keeps personal pet photos private. I would love feedback from stitchers on color matching and grid editing.
